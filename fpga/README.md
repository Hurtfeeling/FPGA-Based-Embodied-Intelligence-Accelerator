# FPGA integration

The packaged bd/design_1.bd and bd/design_1_bd.tcl describe the current ZU15EG system: three GEMM module references, one Softmax, SmartConnect, PS HP0 DDR access, AXI-Lite control windows, PL0 clock and shared reset.

The BD script requires module source files to be present in a Vivado project before it is sourced. `create_project.tcl` adds `GEMM_V2/rtl/*.v`, `Softmax/rtl/*.v`, `Softmax/rtl/softmax_fp32_funcs.vh` and `Softmax/rtl/exp_lut.mem`; the GEMM_V2 DMA modules satisfy the Softmax wrapper's shared DMA references. Then source `bd/design_1_bd.tcl`, validate, generate output products, create the wrapper and run implementation.

The checked-in bitstream and HWH are in three_gemm_softmax/hardware. The BD script was generated by Vivado 2020.1 and may require upgrade with another Vivado version.

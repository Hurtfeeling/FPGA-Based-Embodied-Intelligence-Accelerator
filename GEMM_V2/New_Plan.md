# GEMM_V2 设计说明

当前版本的接入、存储布局、调度和验证入口见 [README.md](README.md)。本目录说明的是当前 GEMM_V2 硬件实现。

实现约束：

1. 基于单 AXI 的 `GEMM` 架构，AXI-Lite 和 ABI 10 保持一致。
2. 宏块采用蛇形遍历，通过输入缓存标签复用相邻宏块所需的 A 或 BT。
3. A、BT 各自为 256 KiB BRAM + 256 KiB URAM，保持统一 3 拍读延迟。
4. 一个宏块内，完整的 32×K A/BT 条带对准备好即可计算。
5. C 结果水位允许后尽早回写，与后台 A/BT 加载及后续计算重叠；宏块切换不要求 C 队列清空。
6. 下一行 DDR 首地址提前寄存，缩短 DMA burst 限长和地址更新路径，不增加每笔 burst 的分配等待拍。
7. 保留原错误中止、已接受 AXI 事务排空及完成状态语义，最终完成仍等待全部 C 写事务与响应。

验证重点：结果正确性、蛇形反向地址与尾块、缓存复用读取量、早写及跨宏块重叠、64 槽 C 所有权、BRAM/URAM 半区边界、4 KiB/跨行地址、错误恢复与复位、同条件总周期和时序对比。
